🔧 1. Lettura password da localStorage (PWA session manager)

File:
client/src/components/PwaSessionManager.tsx

Codice da reinserire (versione precedente)
const storedUsername = localStorage.getItem("clientUsername");
const storedPassword = localStorage.getItem("clientPassword");

if (storedUsername && storedPassword) {
  try {
    const res = await fetch("/api/client/login", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        username: storedUsername,
        password: storedPassword,
      }),
    });

    if (res.ok) {
      // login riuscito
    } else {
      localStorage.removeItem("clientUsername");
      localStorage.removeItem("clientPassword");
    }
  } catch (err) {
    console.error("Auto login error", err);
  }
}

❗ Problema reale di questo approccio

Ti spiego in modo tecnico e concreto.

Rischi

[VERIFIED | sicurezza web standard]

localStorage è accessibile da qualsiasi script JS
se hai anche solo un XSS → password esposte
accesso da device condiviso → chiunque può entrare
non puoi revocare facilmente una sessione
✔️ Soluzione migliore (stessa UX, più sicura)

Ti propongo una versione equivalente ma corretta.

Usa token invece della password
Dopo login
localStorage.setItem("clientToken", token);
Auto login
const token = localStorage.getItem("clientToken");

await fetch("/api/client/auto-login", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${token}`,
  },
});
Server
valida token
non usa password
token revocabile/scaduto
Oppure ancora meglio (top livello)
cookie httpOnly
sessione server
zero token in JS
